Publications

The scientific output associated with the laboratory, and how to consult it today.

Status

No consolidated feed yet

LPS does not currently maintain a public publications feed under the laboratory's responsibility. The scientific output associated with the laboratory is recorded in the professors' Lattes CVs and in the publications of the international collaborations the laboratory takes part in.

Where the output can be consulted

Lattes CVs

Individual, up-to-date record of each professor's output.

ATLAS collaboration (CERN)

Publications of the ATLAS experiment, which carry the laboratory's contribution to online filtering, event simulation and reconstruction.

  • ATLAS — CERN

Code and open data

Public repositories of the LPS GitHub organisation. Externally maintained, with no declared licence — linked, not copied.

  • github.com/lps-ufrj-br

A publication feed requires institutional ownership

Reconciling publication metadata against authoritative sources is migration work, not a design decision. Until then, the laboratory does not publish a list it cannot verify.
