# Scientific Editorial showcase — LEGACY ARCHIVE (demoted)

**Status: archived anti-reference. Not production, not the current contract.**

This directory preserves the warm-paper "Scientific Editorial" primitive
showcase exactly as it existed before the light institutional replacement
(DESIGN.md revision of 2026-09-16, supersede table §1). It is kept as the
historical record of the replaced visual world — the "old look" the contract
now treats as an anti-reference.

What changed and why this was demoted:

- The warm-paper canvas (`#F7F4EC` / `#FFFEFA` / `#ECE8DE`) was replaced by the
  light institutional canvas (`#FFFFFF` / `#FFFFFF` / `#EFF1F4`).
- Serif-first display and headings were replaced by a sans-led hierarchy;
  Source Serif 4 survives only inside reading containers.
- Uniform hairline record rows were replaced by differentiated band modules.

The live executable reference for the current contract is
`showcase/scientific-editorial/` (same path, repurposed in place). The QA lane
(`node scripts/run-qa.mjs design-system`) checks only the live directory; this
archive is not part of any gate and must not be edited to "fix" it — its
contents intentionally describe the superseded system.

Do not copy values, markup, or naming from this archive into new work. If you
need the current tokens, read `wp-content/themes/lps-theme/theme.json` (single
source), `wp-content/themes/lps-theme/assets/css/theme.css`, and the live
showcase.
