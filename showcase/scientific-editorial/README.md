# Scientific Editorial primitive showcase

Standalone, non-production executable reference for root `DESIGN.md`.

```bash
node showcase/scientific-editorial/server.mjs
npm run qa:design-system
node showcase/scientific-editorial/scripts/verify-showcase.mjs
```

The showcase uses no copied institutional assets, tracking, external runtime requests, component framework, or production theme code. Source Serif 4 files are distributed under the included SIL OFL 1.1 license.
